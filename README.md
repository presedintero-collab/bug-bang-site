## Free browser tools — DataFresh & DataDiff

**Official site:** https://twistphysics.org/

| Tool | What it does | Free before/after examples |
| --- | --- | --- |
| [DataFresh](https://twistphysics.org/datafresh.html) | Clean CSV / TSV / JSON / Excel: trim whitespace, remove exact duplicates and fully blank rows | [Messy CSV → cleaned CSV](https://twistphysics.org/data-tools-examples.html) |
| [DataDiff](https://twistphysics.org/datadiff.html) | Compare two datasets using a shared unique ID or row order; export changed, added and removed rows | [Original CSV → updated CSV + change report](https://twistphysics.org/data-tools-examples.html) |

Both tools are free, work in 7 languages and process selected file contents locally in the browser (Excel support uses a CDN-hosted parser). No account is required to use them.
